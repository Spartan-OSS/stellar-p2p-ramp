# Roadmap

These are ordered milestones, not promised dates or staffing guarantees.

| Milestone | Exit evidence |
|---|---|
| 0 — Foundation (supplied) | Domain model, nine tests, architecture, research, issue templates and application draft |
| 1 — Escrow feasibility (implemented) | Original contract selected; ten Soroban tests pass; integration decision documented |
| 2 — Signed CLI testnet flow (verified) | Release and disputed refund confirmed with disposable account signatures; public transaction evidence committed. Browser wallet UX still pending |
| 3 — Contributor readiness | Clean-machine setup, CI, reviewed backlog, licence notices, security reporting and reviewer availability |
| 4 — Programme application | Public organisation/repository, submitted programme application and eventual approval if granted |
| 5 — Marketplace MVP | Atomic offer reservations, immutable quotes, reliable event worker, evidence access, merchant tools |
| 6 — Controlled real-money pilot | Independent contract review, payment-provider/regulatory route, verified merchants, dispute operations and treasury/fee policy |

## Success measures to collect

Setup success, testnet trade completion, reservation conflicts correctly rejected, event-replay consistency, dispute completion time, contributor PR review turnaround and recurring contributor retention. No baseline values are claimed yet.
